# Chișinău 2040: ce contează — сайт опроса жителей

Отдельный сайт для опроса жителей при разработке PUG Chișinău 2040. Отвечать можно без регистрации, с телефона или компьютера, на румынском или русском. Ответы сохраняются в вашу Google-таблицу.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Весь сайт: опрос из 6 шагов, карта OpenStreetMap, вкладка результатов |
| `apps-script.gs` | Бэкенд: принимает ответы и считает результаты, работает внутри Google-таблицы |
| `README.md` | Эта инструкция |

Сервер, база данных и программирование не нужны. Всё бесплатно.

## Установка за 15 минут

### 1. Создайте таблицу и бэкенд

1. Откройте [sheets.new](https://sheets.new) под Google-аккаунтом, который будет владельцем данных (лучше служебный аккаунт проекта, а не личный). Назовите таблицу, например, «Chișinău 2040 — răspunsuri».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите код в редакторе, вставьте целиком содержимое `apps-script.gs`, нажмите **Сохранить**.
4. Нажмите **Начать развертывание → Новое развертывание**.
   - Тип: **Веб-приложение**.
   - Выполнять от имени: **Меня**.
   - У кого есть доступ: **Все** (именно «Все», иначе жители не смогут отправить ответ).
5. Нажмите **Развернуть**, разрешите доступ к таблице и скопируйте **URL веб-приложения**. Он выглядит так: `https://script.google.com/macros/s/…/exec`.

### 2. Подключите сайт к бэкенду

Откройте `index.html` в любом текстовом редакторе, найдите строку

```js
const API_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
```

и вставьте вместо текста в кавычках скопированный URL.

### 3. Опубликуйте сайт

Подойдёт любой хостинг статических файлов. Три варианта:

- **Netlify Drop** (быстрее всего): откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите папку с `index.html`. Через минуту получите адрес вида `…netlify.app`.
- **GitHub Pages**: создайте репозиторий, загрузите `index.html`, включите Pages в настройках.
- **Сервер примэрии или pug.chisinau.md**: передайте `index.html` администратору сайта. Его можно положить в отдельную папку, например `pug.chisinau.md/sondaj/`.

### 4. Проверьте

Пройдите опрос сами и отправьте ответ. В таблице появится строка, а во вкладке «Rezultate» сайта — ваш ответ (результаты обновляются раз в минуту).

## Как это работает

- **Один ответ на устройство.** Браузер получает случайный идентификатор. Повторная отправка с того же устройства обновляет ответ, а не создаёт новый. Это защищает от случайных дублей, но не от целенаправленной накрутки (другой браузер — новый ответ). Для голосований с юридическими последствиями нужна идентификация через MPass.
- **Персональные данные не собираются**: ни имени, ни телефона, ни email. В таблице только ответы, сектор, возрастная группа и тип жилья. Google как платформа ведёт свои технические журналы.
- **Защита от спама**: скрытое поле-ловушка для ботов и проверка всех значений на сервере.
- **Координаты.** Каждая отметка на карте сохраняется с широтой и долготой, поэтому таблицу можно загрузить в QGIS или ГИС разработчика PUG.

## Модерация

Свободные ответы («почему сохранить», «что убрать») показываются анонимно на вкладке результатов.

- Чтобы скрыть конкретный ответ, поставьте `1` в колонке `hidden` его строки.
- Чтобы не показывать свободные ответы вообще, в `apps-script.gs` поменяйте `SHOW_TEXT_IN_RESULTS = true` на `false` и сделайте **Развертывание → Управление развертываниями → Изменить → Новая версия**.

После любого изменения кода Apps Script нужно выпускать новую версию развертывания, иначе сайт продолжит работать со старой.

## Структура таблицы

| Колонка | Содержание |
|---|---|
| `id` | Идентификатор устройства |
| `updatedAt` | Время последней отправки |
| `lang` | Язык интерфейса: `ro` или `ru` |
| `sector` | 0 Botanica, 1 Buiucani, 2 Centru, 3 Ciocana, 4 Râșcani, 5 село или город муниципия, 6 за пределами Молдовы |
| `age` | 0 до 18, 1 18–29, 2 30–44, 3 45–64, 4 65+ |
| `tenure` | 0 собственник, 1 арендатор, 2 живёт с семьёй |
| `commute`, `mode` | Время в пути (мин) и способ: 0 пешком, 1 ОТ, 2 автомобиль, 3 велосипед/самокат, 4 из дома |
| `thr` | Пороги: [время до работы, мин; до зелени, мин; доля дохода на жильё, %; до школы, мин] |
| `pairs` | Выборы с ценой, 0 — первый вариант, 1 — второй |
| `budget` | 100 очков: транспорт, зелень, жильё, школы, наследие, безопасность |
| `keep`, `prob` | Отметки на карте: широта, долгота, комментарий |
| `identity`, `remove`, `diaspora` | Свободные ответы |
| `hidden` | 1 — скрыть из публичных результатов |

## Ограничения и что учесть перед массовым запуском

- **Карта.** Подложка берётся с серверов OpenStreetMap; если они отвечают ошибкой, сайт сам переключается на карту Esri World Street Map, затем на OSM France. Бесплатные тайлы рассчитаны на умеренную нагрузку: для кампании на десятки тысяч жителей подключите платного поставщика (MapTiler, Stadia Maps и т. п.) — это правка списка `TILES` в `index.html`. Тайлы OpenStreetMap отвечают ошибкой 403, если открыть `index.html` двойным щелчком с диска: проверяйте сайт уже размещённым на хостинге.
- **Квоты Google.** Apps Script бесплатно выдерживает тысячи ответов в день; одновременно обрабатывается около 30 отправок, лишние ждут в очереди несколько секунд.
- **Представительность.** Онлайн-опрос не отражает весь город. Дополните его офлайн-анкетами (поликлиники, рынки, примэрии сёл) и сверяйте ответы с квотами по возрасту и секторам.
- **Правовая сторона.** Перед запуском согласуйте текст о данных с юристом примэрии с учётом закона Республики Молдова о защите персональных данных.
